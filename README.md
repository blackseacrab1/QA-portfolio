### Automation QA

Занимаюсь внедрением и развитием автоматизации.  
Пишу UI-автотесты по модели Page Object Model — каждый тест независимый, легко поддерживается и масштабируется.  
Также разрабатываю API-автотесты с полным покрытием CRUD и авторизации.

На реальных проектах самостоятельно внедрил автоматизацию в GitLab CI.

- Ручное тестирование — функциональное, exploratory, smoke, regression, UI/UX, тест-дизайн
